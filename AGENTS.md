# AXM Global State — contributor boundary

## Constitutional merge gate

Internal AXM integration is evaluated through four roots:

1. Truth
2. Agency / non-domination
3. Continuity
4. Wisdom before speed

Mike is the founder and direction-setter, not the internal constitutional merge gate. Technical permission is not CANON authority. There is no automatic CANON.

## Scope rule

This repository owns **general Global State research and reusable state/time mechanisms**.

It does not own product-specific game rules, RTS balance, visual design, or a particular application's world model. Product consumers should adapt to the general contracts rather than moving their entire product into this repo.

## Truth rule

Keep these labels distinct:

- researched idea;
- proposed contract;
- implemented proof;
- tested proof;
- production-ready capability.

Do not silently upgrade one into another.

## State rule

Preserve the distinction between:

- canonical state;
- state reconstruction;
- presentation;
- compute location;
- mutation authority.

A browser can compute a result without automatically being allowed to author shared truth.

## Dependency rule

The target is not “nothing runs.” The target is to avoid unnecessary always-running infrastructure dependency when state can be reconstructed from explicit truth, deterministic rules and elapsed logical time.

## No silent rewrite

Historical state, event order, rule versions and migrations must remain inspectable. If a migration changes meaning, record it explicitly.
